## ✦ Main Project

### Task Planner

A production-ready task planning app available on the App Store.

<p>
  <a href="https://apps.apple.com/us/app/task-planner-daily-schedule/id6762282029" target="_blank">
    <img src="https://img.shields.io/badge/App%20Store-Download-0D96F6?logo=appstore&logoColor=white" />
  </a>
</p>

Task Planner is a local-first productivity app with recurring tasks, calendar planning, statistics, widgets, reminders, Apple Calendar integration, and subscriptions.

Key features:
- recurring tasks with flexible repeat rules
- calendar-based planning
- all-day, timed, multi-day, and repeating tasks
- day / week / month / year statistics
- interactive widgets
- local notifications
- Apple Calendar import/export
- task photo attachments
- subscription model with StoreKit 2
- custom animations and adaptive SwiftUI layouts

Tech:
Swift, SwiftUI, SwiftData, MVVM, Clean Architecture, Combine, Swift Concurrency, UserNotifications, EventKit, WidgetKit, StoreKit 2, PhotosUI, Charts, Git
