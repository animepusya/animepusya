## ✦ Current Project

### Mind Widgets (In Development)

Modern iOS 17+ application focused on personal widgets, phrase collections, and on-device AI features.

Key features:
- Apple Intelligence integration using Foundation Models
- WidgetKit with App Group data sharing
- SwiftData persistence layer
- JSON export/import
- Custom widget rendering and image processing
- Feature-based MVVM architecture
- Dependency Injection and protocol-oriented design
- Local notifications and widget synchronization

Tech:
Swift, SwiftUI, SwiftData, Foundation Models, WidgetKit, App Groups, CoreGraphics, UserNotifications
